# Research notes

How TW05's online side was worked out, from reading the game's executable
(`SLUS_210.02`) and watching a live game talk to this server. They are working
notes rather than a finished reference: dated, in the order things were found,
with guesses marked as guesses. The [TW04 server's protocol
notes](https://github.com/jeddyhhh/TW04OnlineServer/blob/main/docs/PROTOCOL.md)
cover the lobby protocol the two games share; these cover what TW05 does
differently.

| Note | What it covers |
|---|---|
| [tw05-recon.md](tw05-recon.md) | **Start here.** The first reading of the executable: where it connects (by name, `ps2tw05.ea.com:20200`), what changed from TW04, the DNAS patch, pointing the game at a server by writing its IP over the host names, and the real-PS2 master code. |
| [tw05-tournament.md](tw05-tournament.md) | The date, season and online tournament calendar: TW05's renamed commands, the 60-byte event entry, conditions, course codes, and the round report. |
| [tw05-games.md](tw05-games.md) | Head-to-head play: TW05's game adverts (`gcre`/`gsea`/`gjoi`), the session push, the four game modes (stroke, match, 3 Hole Mini-Game, Battle), and the first real matches. |
| [tw05-stats.md](tw05-stats.md) | The player record behind MY RESUME (94 packed bit-fields), and online cash: starting balance, tournament winnings and wagers. |
| [tw05-messenger.md](tw05-messenger.md) | EA Messenger: what TW05 adds to TW04's (user search, and friend requests that the other player accepts), the roster `ATTR` letters, and the invitation verbs not yet answered. |
| [tw05-voice.md](tw05-voice.md) | Voice chat over a USB headset: how it starts, its port, and its audio codec. Read from the code, not yet heard live. |
| [tw05-lobby-requests.txt](tw05-lobby-requests.txt) | Every lobby request the game can send: verb, tags, callback. Generated by [`analysis/requests_map.py`](../analysis/README.md). |

Addresses are virtual addresses in the executable (file offset + `0xFF000`);
see [analysis/README.md](../analysis/README.md).
